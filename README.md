# Лабораторная работа: Линейные алгоритмы

## Автор
Чеботников А.В. (Вариант 8)

## Цель
Освоение базового синтаксиса C++ и математических вычислений на примере расчёта теплового потока через стенку.

## Описание
Программа вычисляет величину теплового потока Q через металлическую стенку трёх форм: плоскую, цилиндрическую и шаровую. Расчёт ведётся по трём формулам из задания.

## Исходные данные
- Теплопроводность λ: 59.034 Вт/(м·град)
- Внутренний радиус R₁: 0.252 м
- Наружный радиус R₂: 0.293 м
- Внутренняя температура t₁: 264.0 °C
- Наружная температура t₂: 43.0 °C
- Площадь плоской стенки F: 0.53 м²
- Длина цилиндрической стенки L: 1.0 м

## Ожидаемые результаты
Программа выводит три значения теплового потока:
- Q1: через плоскую стенку
- Q2: через цилиндрическую стенку
- Q3: через шаровую стенку
